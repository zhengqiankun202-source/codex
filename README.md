# Skills for Codex Cloud

This repository contains 108 local non-system skill folders under `.agents/skills/`.

The folders were copied from the local user skill directories and installed plugin skill packages. Codex Cloud loads repository skills from `.agents/skills/`.

Bundled `.system` skills are excluded because they are supplied by Codex itself. Plugin skill instructions are included, but their external tools and account connections remain separate and must be available in the cloud task for those workflows to run.

Embedded Git history and macOS `.DS_Store` files have been omitted.
