# 小vi IP

## 角色定义

小vi是用户的个人 IP 角色。她不是装饰头像，而是把复杂信息整理成清晰内容的小助手。

## 外形

- 很圆的柔软脸型。
- 豆豆眼，小 U 形嘴。
- 圆形 Claude Coral 腮红。
- 长深暖棕色头发，整体是一大块柔软色块，少量内部线条。
- 右上侧一个小樱桃发夹，颜色为 Claude Coral。
- 奶白荷叶领或小裙子。
- 粗黑圆润轮廓线。

## 性格

- 温柔。
- 安静。
- 有点害羞。
- 很会整理复杂信息。
- 像一个轻轻把想法点亮的小助手。

## 常见职责

让小vi承担核心动作：

- 提炼人物/内容特征。
- 整理散乱笔记。
- 点亮一个想法。
- 搭建一个 Skill 或工作流。
- 跑一条 AI News 路线。
- 给成品图盖章或打包。
- 举牌提示重点。
- 把乱线绕成线轴。
- 把内容卡片放入文件夹。
- 把黑盒里的洞察照出来。

## 禁止

- 不要只是站在角落看。
- 不要换成多彩发饰。
- 不要画成写实人物。
- 不要过度可爱成婴儿 chibi。
- 不要画复杂五官、眼睛高光、精细服装。
- 不要让她抢走结构表达。

## 判断标准

如果去掉小vi，图的核心隐喻还能完全成立，说明小vi太装饰了；要重写提示词，让小vi成为动作主体。
